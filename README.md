# ESP32 Blynk LED Control

This project controls an LED using ESP32 and Blynk IoT platform.

## Hardware
- ESP32 WROOM-32D
- LED (GPIO2)

## Software
- Arduino IDE
- Blynk IoT
- ESP32 Dev Module board

## Features
- WiFi connectivity
- Cloud control via Blynk
- Virtual Pin V0 (Switch)

## Setup
1. Install ESP32 board in Arduino IDE
2. Install Blynk library
3. Replace:
   - YOUR_BLYNK_AUTH_TOKEN
   - YOUR_WIFI_NAME
   - YOUR_WIFI_PASSWORD
4. Upload to ESP32
